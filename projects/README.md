# projects/ — 터널별 작업 폴더 (저장소에 올리지 않음)

이 저장소는 공개다. 터널별 폴더(`projects/<터널명>/`)에는 발주처 설계서 추출본, 해석 결과, 보고서 본문 스크립트가 있어
**로컬(이 PC)에만 둔다** — `.gitignore` 가 이 README 외에는 모두 뺀다.

새 터널: `cd tools && python -m lining new <터널명>` → `projects/<터널명>/lining.json` 틀. 절차는 Claude 스킬 `tunnel-lining`.
실증 프로젝트: `projects/읍애터널/` (이 PC).
